# Site-Amor V2 ❤️

Versão preparada para o marco de **2 meses + 400 km de distância**.

## O que foi melhorado
- abertura com envelope/carta premium;
- tema visual de 2 meses + 400 km;
- contador em tempo real desde 17/07/2026;
- contagem regressiva automática até 17/09/2026;
- seção especial da distância;
- galeria com 5 fotos e visualização ampliada;
- carta reescrita e corrigida;
- cápsula/promessa para o futuro;
- surpresa final mais elaborada;
- favicon usando `assets/logo-amor.png`;
- player preparado para **Girassóis de Van Gogh — The Ralph & Freittas**;
- botão para ouvir a música online;
- layout responsivo para celular.

## Música
Para tocar a música dentro do próprio site, coloque uma cópia autorizada do arquivo em:

`audio/girassois-de-van-gogh.mp3`

O site já procura exatamente esse nome.

## Railway / GitHub
Como o projeto é um site estático, você pode substituir os arquivos do seu repositório e fazer commit/push normalmente. Se o Railway estiver conectado ao GitHub, o novo commit pode disparar o deploy automaticamente.

## Importante
A música não foi embutida no ZIP porque é uma gravação comercial. O player local fica pronto para receber um arquivo que você tenha direito de usar.
